Kebijakan Privasi - Duniawi

Terakhir diperbarui: 6 November 2026
Berlaku untuk: Duniawi versi 1.2.0 ke atas (paket com.kodingkita.duniawi)

Bahasa Indonesia

1. Prinsip dasar

Duniawi adalah aplikasi pencatatan keuangan pribadi yang berjalan di perangkatmu. Aplikasi ini tidak punya akun, tidak punya login, dan tidak punya server milik pengembang. Seluruh catatan keuangan, dompet, daftar belanja, catatan hutang-piutang, dan foto yang kamu simpan berada di penyimpanan privat aplikasi di perangkatmu sendiri. Pengembang tidak punya cara untuk melihat data itu.

Ada dua pengecualian di mana data meninggalkan perangkat, dan dua-duanya dijelaskan terpisah di bawah: analitik penggunaan (bagian 3) dan fitur opsional Baca struk pakai AI (bagian 4).

2. Data yang disimpan di perangkat (tidak dikirim ke mana pun)

  • Transaksi, nominal, dompet, dan alokasi uang.
  • Daftar belanja dan itemnya.
  • Catatan hutang dan piutang, termasuk nama orang yang kamu tulis sendiri.
  • Foto struk dan foto bukti pembayaran.
  • Berkas backup yang kamu buat sendiri (ZIP berisi data dan foto). Berkas ini tersimpan di lokasi yang kamu pilih; kalau kamu membagikannya, kamu yang menentukan ke mana berkas itu pergi.

Akses kontak (izin READ_CONTACTS): hanya dipakai untuk menyarankan nama saat kamu mengisi catatan hutang-piutang. Daftar kontakmu dibaca di perangkat dan tidak pernah dikirim ke mana pun.

Kamera (izin CAMERA): hanya dipakai saat kamu memotret struk atau bukti pembayaran. Fitur ini bisa jalan dari galeri juga, jadi kamera tidak wajib ada di perangkatmu.

3. Analitik (Firebase Analytics)

Duniawi memakai Google Firebase Analytics untuk mengetahui fitur mana yang dipakai dan di mana aplikasi gagal, supaya aplikasinya bisa diperbaiki.

Yang dikirim hanya BENTUK perilaku, bukan isi datamu. Besaran dikirim sebagai label rentang (misalnya 1-5, 16-30, 3-8s), bukan angka aslinya. Secara spesifik, Duniawi tidak pernah mengirim ke analitik:

  • nominal uang, saldo, atau total transaksi,
  • nama dompet, catatan, atau teks yang kamu tulis,
  • nama kontak, nomor telepon, atau isi pesan pengingat,
  • kata kunci pencarian,
  • foto, atau
  • API key.

Duniawi juga menonaktifkan Advertising ID (izin AD_ID dihapus dari aplikasi) dan tidak menampilkan iklan.

Kebijakan privasi Firebase: https://firebase.google.com/support/privacy

4. Fitur opsional: Baca struk pakai AI (API key milikmu sendiri)

Ini satu-satunya bagian Duniawi yang mengirim FOTO keluar dari perangkatmu. Fitur ini mati secara bawaan dan tidak bisa menyala tanpa kamu menempelkan API key milikmu sendiri.

Duniawi bisa membaca struk dengan dua cara:

  1. Di perangkat (bawaan). Struk dibaca memakai Google ML Kit yang modelnya ikut di dalam aplikasi. Tidak butuh internet dan tidak ada apa pun yang keluar dari perangkat.
  2. Lewat model AI pilihanmu (opsional). Kalau kamu menyalakan fitur ini dan menempelkan API key milikmu, foto struk dikirim ke penyedia model yang kamu pilih untuk dibaca.

Apa yang dikirim, dan risikonya. Yang dikirim adalah foto struknya — dan foto struk bisa memuat nama toko, alamat toko, tanggal dan jam belanja, daftar barang yang kamu beli, nominal yang kamu bayar, serta apa pun yang ikut terfoto di sekitarnya. Kalau foto tidak tersedia, Duniawi mengirim teks hasil pembacaan di perangkat yang sudah diredaksi lebih dulu (alamat, nomor telepon, nama kasir, nomor kartu, tanggal, dan jam dibuang).

Ke mana dikirim. Langsung dari perangkatmu ke penyedia yang kamu pilih, memakai HTTPS. Permintaan ini tidak melewati server pengembang — pengembang tidak punya server dan tidak pernah melihat foto, teks, maupun API key-mu.

Penting: begitu foto itu sampai di penyedia model, yang berlaku adalah kebijakan penyedia tersebut, bukan kebijakan ini. Berapa lama mereka menyimpannya, apakah dipakai untuk melatih model, dan di negara mana datanya diproses — itu ditentukan oleh penyedia dan oleh jenis akun/API key yang kamu pakai. Baca kebijakan penyedia pilihanmu sebelum menyalakan fitur ini. Duniawi tidak bisa mengendalikan atau menghapus data yang sudah ada di sisi penyedia.

API key-mu. Disimpan terenkripsi di perangkat memakai Android Keystore (flutter_secure_storage), satu slot per penyedia. Key hanya dikirim ke penyedia yang memilikinya sebagai tanda autentikasi, dan tidak pernah dikirim ke pengembang maupun ke penyedia lain. Key tidak pernah ditampilkan kembali di layar. Kamu bisa menghapusnya kapan saja dari Setelan → Scan Struk AI.

Cara mematikan. Matikan sakelar Baca struk pakai AI di Setelan, atau hapus API key-nya. Setelah itu tidak ada lagi apa pun yang keluar dari perangkat, dan pembacaan struk kembali sepenuhnya di perangkat. Mematikan fitur ini tidak menghilangkan fungsi apa pun selain tingkat akurasi pembacaan.

Membuat API key. Persyaratan pembuatan API key ditentukan oleh masing-masing penyedia dan bisa berbeda tiap negara (misalnya verifikasi umur, negara, atau jenis akun). Hal itu di luar kendali Duniawi.

5. Anak-anak

Duniawi tidak ditujukan untuk anak di bawah 13 tahun dan tidak mengumpulkan data dari mereka secara sengaja. Fitur Baca struk pakai AI mensyaratkan API key dari penyedia pihak ketiga, yang punya batasan umurnya sendiri.

6. Keamanan

  • Data aplikasi berada di penyimpanan privat aplikasi, dilindungi oleh sandbox Android.
  • API key disimpan di Android Keystore, bukan di penyimpanan biasa.
  • Semua pengiriman data ke luar perangkat memakai HTTPS (terenkripsi saat transit).
  • Tersedia kunci aplikasi memakai biometrik/PIN perangkat yang bisa kamu nyalakan sendiri.
  • Karena tidak ada akun dan tidak ada server, tidak ada basis data pengguna di sisi pengembang yang bisa bocor.

7. Menghapus data

Tidak ada akun yang perlu dihapus. Kamu bisa menghapus data langsung di aplikasi (per catatan, per foto, atau per API key), atau menghapus seluruhnya dengan menghapus aplikasi atau Hapus data di pengaturan Android. Data yang sudah pernah dikirim ke penyedia model (bagian 4) harus kamu urus lewat penyedia tersebut. Untuk data analitik, hubungi pengembang di alamat pada bagian 9.

8. Perubahan kebijakan

Kebijakan ini bisa berubah seiring aplikasi berkembang. Tanggal "Terakhir diperbarui" di atas selalu menandai versi yang berlaku. Perubahan yang menyangkut data keluar perangkat akan dinyatakan juga di dalam aplikasi, pada layar fitur yang bersangkutan.

9. Kontak

Privacy Policy - Duniawi

Last updated: 6 November 2026
Applies to: Duniawi version 1.2.0 and later (package com.kodingkita.duniawi)

English Version

1. Core principle

Duniawi is a personal finance app that runs on your device. It has no accounts, no login, and no developer-operated server. All of your transactions, wallets, shopping lists, debt records, and photos live in the app's private storage on your own device. The developer has no way to see any of it.

There are two exceptions where data leaves your device, each described separately below: usage analytics (section 3) and the optional Read receipts with AI feature (section 4).

2. Data kept on your device (never transmitted)

  • Transactions, amounts, wallets, and money allocations.
  • Shopping lists and their items.
  • Debt and receivable records, including names you type yourself.
  • Receipt photos and payment-proof photos.
  • Backup files you create (a ZIP containing your data and photos). The file is saved where you choose; if you share it, you control where it goes.

Contacts access (READ_CONTACTS): used only to suggest names while you fill in a debt record. Your contacts are read on the device and never transmitted anywhere.

Camera (CAMERA): used only when you photograph a receipt or a payment proof. The feature also works from the gallery, so camera hardware is not required.

3. Analytics (Firebase Analytics)

Duniawi uses Google Firebase Analytics to learn which features are used and where the app fails, so it can be improved.

Only the SHAPE of behaviour is sent, never your content. Magnitudes are sent as bucket labels (for example 1-5, 16-30, 3-8s), not real values. Specifically, Duniawi never sends to analytics:

  • monetary amounts, balances, or transaction totals,
  • wallet names, notes, or any text you write,
  • contact names, phone numbers, or reminder message bodies,
  • search queries,
  • photos, or
  • API keys.

Duniawi also disables the Advertising ID (the AD_ID permission is removed from the app) and shows no ads.

Firebase privacy policy: https://firebase.google.com/support/privacy

4. Optional feature: Read receipts with AI (your own API key)

This is the only part of Duniawi that sends a PHOTO off your device. The feature is off by default and cannot be enabled without you pasting in your own API key.

Duniawi can read a receipt two ways:

  1. On device (default). The receipt is read with Google ML Kit, whose model ships inside the app. No internet is needed and nothing leaves your device.
  2. Through an AI model you choose (optional). If you enable this feature and paste your own API key, the receipt photo is sent to the model provider you selected to be read.

What is sent, and the risk. What is sent is the receipt photo — and a receipt photo can contain the store name, the store address, the date and time of purchase, the list of items you bought, the amount you paid, and anything else caught in the frame. If no photo is available, Duniawi sends the on-device text instead, redacted first (addresses, phone numbers, cashier names, card numbers, dates, and times are stripped).

Where it is sent. Directly from your device to the provider you chose, over HTTPS. The request does not pass through any developer server — there is none, and the developer never sees your photo, your text, or your API key.

Important: once the photo reaches the model provider, that provider's policy governs it, not this one. How long they retain it, whether it is used to train models, and which country it is processed in are determined by the provider and by the kind of account or API key you use. Read your chosen provider's policy before enabling this feature. Duniawi cannot control or delete data already held by a provider.

Your API key. Stored encrypted on the device using the Android Keystore (flutter_secure_storage), in a separate slot per provider. A key is sent only to the provider it belongs to, as an authentication credential, and never to the developer or to any other provider. A saved key is never displayed back on screen. You can delete it at any time from Settings → Scan Struk AI.

How to turn it off. Switch off Baca struk pakai AI in Settings, or delete the API key. After that nothing leaves your device again and receipt reading returns to fully on-device. Turning it off removes no functionality other than reading accuracy.

Creating an API key. The requirements for creating an API key are set by each provider and can differ by country (for example age verification, country, or account type). That is outside Duniawi's control.

5. Children

Duniawi is not directed at children under 13 and does not knowingly collect data from them. The Read receipts with AI feature requires a third-party API key, and those providers enforce their own age requirements.

6. Security

  • App data lives in the app's private storage, protected by the Android sandbox.
  • API keys are held in the Android Keystore, not in ordinary preferences.
  • All data leaving the device is sent over HTTPS (encrypted in transit).
  • An optional app lock using device biometrics/PIN is available.
  • Because there are no accounts and no server, there is no developer-side user database that could be breached.

7. Deleting your data

There is no account to delete. You can delete data inside the app (per record, per photo, or per API key), or remove everything by uninstalling the app or using Clear data in Android settings. Data already sent to a model provider (section 4) must be handled through that provider. For analytics data, contact the developer at the address in section 9.

8. Changes to this policy

This policy may change as the app evolves. The "Last updated" date above always marks the version in force. Any change involving data leaving the device will also be stated inside the app, on the screen of the feature concerned.
